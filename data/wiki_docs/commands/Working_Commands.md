# Working Commands

With working commands, you can collect materials which you need for crafting. Each command can be upgraded to a better command when you reach a certain area.

Those are the working commands and the area needed to unlock them:
| Wood | Area | Fish | Area | Apple |  | Ruby |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| chop | 1 | fish | 1 | pickup | 3 | mine | 5 |
| axe | 3 | net | 3 | ladder | 4 | pickaxe | 6 |
| bowsaw | 6 | boat | 6 | tractor | 8 | drill | 10 |
| chainsaw | 9 | bigboat | 9 | greenhouse | 11 | dynamite | 12 |


1. #  Chop 
| Wood | Description | Command | Area |
| --- | --- | --- | --- |
| chop | In area 1 you can chop wood this is needed for crafting armor/swords | /chop | 1+ |
| axe | In area 3 you can use this command to get more logs than the original command. | /axe | 3+ |
| bowsaw | In area 6 you can use this command to get even more logs | /bowsaw | 6+ |
| chainsaw | In area 9 you can use this command to get an abundance of logs to help you work towards any of your crafting needs. | /chainsaw | 9+ |


1. #  Fish 
| Fish | Description | Command | Area |
| --- | --- | --- | --- |
| fish | In area 1 you can use the command to collect fish for crafting | /fish | 1+ |
| net | In area 3 you can use this command to collect more fish | /net | 3+ |
| boat | In area 6 you can use this command to get even more fish | /boat | 6+ |
| bigboat | In area 9 you can use this command to get extra amounts of fish | /bigboat | 9+ |


1. #  Pickup 
| Fruit | Description | Command | Area |
| --- | --- | --- | --- |
| pickup | In area 3 you can start collecting apples and bananas for crafting armor/swords | /pickup | 3+ |
| ladder | In area 4 you can use this command to get more apples and bananas than the original command | /ladder | 4+ |
| tractor | In area 8 you can use this command to get even more fruits | /tractor | 8+ |
| greenhouse | In area 11 you can use this command to get even extra fruits | /greenhouse | 11+ |


1. #  Mine 
| Ruby | Description | Command | Area |
| --- | --- | --- | --- |
| mine | In area 5 you can start digging for a small number of coins and a very rare chance to get rubies to be either sold or traded in for wood | /mine | 5+ |
| pickaxe | In area 6 you can use this command to dig for more coins and a slightly increased chance to get a ruby | /pickaxe | 6+ |
| drill | In area 10 you can use this command to dig for even more coins and a higher chance for rubies | /drill | 10+ |
| dynamite | In area 12 you can use this command to dig for large amounts of coins and a greater chance for rubies | /dynamite | 12+ |
