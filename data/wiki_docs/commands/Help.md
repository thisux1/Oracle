# Help

The command **/help** provides a list of all commands, as well as helpful links to invite the bot, join the official server, and view the bot's Patreon. The commands are divided into the following categories:

- Statistics: Commands related to your profile and leaderboards are listed here.
- Fighting: Commands related to your adventure are listed here.
- Economy: Commands related to buying and selling items are listed here.
- Working: Commands related to obtaining items through working and crafting recipes are listed here.
- Gambling: Commands to tell you how to waste your money.
- More Rewards: Always-accessible commands that do not fall under any of the above categories are listed here.
- Commands Unlocked in Higher Areas: Commands unlocked for each area from 2 to 15 are listed in order in this section. Refer to the wiki page for the respective area to see what commands are unlocked in which area.
- Event Commands: If there is a current event, any command related to the event will be listed near the bottom of the help embed.

Specific information about a particular command, item or event can be obtained by running the command **/help [command/item/event name]**.
