# Commands

Click the command for detailed information, the prefix of the bot is **rpg**, **/** or **@EPIC RPG**

    - Usage examples**: "rpg start", "rpg hunt", "/profile", "@EPIC RPG adventure"

1. #  Basic commands 
| Command | Description | Alias |
| --- | --- | --- |
| help | See a list of all commands. Additionally, can display more information on most items/commands. | h, commands |
| rules (Ver: EPIC RPG Wiki#Rules) | Displays some of the major Discord ToS rules that players should not violate. |  |
| start | Displays basic information to help give players an idea of where and how to start. |  |
| profile | Shows your current statistics, use 'profile @player' to see another player's stats. | p |
| inventory | Shows your inventory, use 'inventory @player' to see another player's inventory. | i, inv |
| professions | Shows your professions' progress, use "professions [profession]" to see exact profession experience and a basic description of the profession. | pr, profession |
| top | Shows the top players (there are server and global leaderboards). | leaderboard, ranking |
| cooldowns (Ver: Cooldowns#Commands) | Shows your cooldown timers, use 'cd @player' to see another player's cooldowns. | cooldown, cd, cds |
| ready (Ver: Cooldowns#Commands) | Shows your cooldown timers, but only the ready ones. Use 'rd @player' to see another player's cooldowns that are ready. | rd |
| quest | Shows your current quest if you have one, or get a new one if it is off cooldown. Use quest quit to leave your current quest. |  |
| epic quest | Embark on an Epic Quest and fight against up to 15 or 100 waves of enemies. Requires you to have a SPECIAL horse type or a SUPER SPECIAL horse type. |  |
| horse | Shows the stats of your current horse. 'Use horse @player' to see another player's horse. |  |
| title (Ver: Achievements#Titles) | Shows the available titles for your profile and how to unlock them. | titles |
| achievements | Shows your achievements. Use 'ach @player' to see another player's achievements. | achievement, ach |
| background | Shows the available backgrounds for your profile. | bg |
| hunt | Used to find mobs to get XP and coins. |  |
| adventure | Go on an adventure to kill a difficult enemy in your current area. | adv |

| dungeon | Use dungeon @player to go into the max area's dungeon with a partner and unlock the next area. | dung |

| shop | Used to show the items shop. |  |
| lootbox | Shows the available lootboxes and their possible contents. | lb |

| fish (Ver: Working#Fish) | Go fishing for fish, shares a cooldown with the other working commands. |  |

| recipes (Ver: Crafting) | Shows the available recipes. | recipe |
| dice (Ver: Gambling#Dice) | Throws a dice to gamble. |  |
| cups (Ver: Gambling#Cups) | Gamble your money trying to find a square. |  |
