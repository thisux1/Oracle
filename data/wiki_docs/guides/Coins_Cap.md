# Coins Cap

As of July 3, 2020, a cap to the number of coins that could be possessed by an account before it could no longer receive coins from the give (Ver: Commands) and multidice (Ver: Gambling#multidice) commands was introduced. The way that this coin cap is calculated follows by:

Give/Multidice Cap = 500,000,000 * T^4 + 100,000 * A^2,

where T is the number of time travels (Ver: Time Travel) and A is the maximum area of an account.
For example:
- In TT0 A10, it would be 0^4 * 500,000,000 + (100,000 * 10^2) = 10,000,001 coins
- In TT1 A10, it would be 1^4 * 500,000,000 + (100,000 * 10^2) = 510,000,000 coins
- In TT2 A10, it would be 2^4 * 500,000,000 + (100,000 * 10^2) = 8,010,000,000 coins


If a player reaches their given coin cap, there is no way to receive more coins from players unless they have a higher coin cap than their amount of coins.

There is also a coin cap for boosted minibosses (Ver: Regular Events#Miniboss%20Lists), although it doesn't apply for the host. It is expected to be similar as give and multidice coin cap.
