# Marry

The marriage system in the game is unlocked with Patreon benefits (Super Donator and above). It allows two players to marry each other and unlock the hunt together (Ver: Hunt#Hunt Command Variations) command, as well displaying the username in the profile of the other user. 

    - Usage:** /hunt together / rpg hunt t 

- Only one of the two players needs to be a Super Donator or above to unlock this command to get married. 

- This command allows one of the users to trigger the hunt for both users at once so the other person does not need to hunt. You can optimize the usage of this by trying to find someone that is of the opposite time zone from your own.

- The hunt together command applies the Tier 4 horse buff: Immortality. This means that if one of the players is to die, the other player will save them. And if both players almost die, they will save each other.


    - Note:** You will still be married even if you or your partner's super donator perk runs out. And you will still be able to use hunt together command unless one of you divorces.


1. #  Divorce 
It is possible to divorce with **/divorce;** no special requirement is needed for this command other than being married.
