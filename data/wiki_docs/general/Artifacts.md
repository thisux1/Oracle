# Artifacts

Artifacts were introduced into the game on August 28th 2023. The purpose of artifacts is to grant various bonuses to the player. 

    - /Artifacts** shows which items you have collected and which artifacts you have active.
1. #  **Requirements** 
(TT1+) The player have to have time travelled at least once before being eligible to collect artifact parts. 

For some parts of the artifacts, you would have to have progressed far into time travels to be able to obtain the parts, this is specifically true when it comes to the **Master Key** & **Pocket Watch**. 

1. #  Obtaining Artifacts 
To obtain artifacts, you must collect all the parts needed to craft them - artifacts can be crafted with the **/craft** command followed by the artifact name.

1. ##  Top Hat 

      - *Description:** *Unlocks the daily deal in trade ( 100+(1+TT Count)^1.35 trades per day) and multiplies x5 the inventory item cap, gets better with time travels.***

|  | **Part** | **Gained from** |
| --- | --- | --- |
|  | **A** | **/hunt** commands in Area 3, Area 5 & TOP |
|  | **B** | **/adventure** commands in Area 3, Area 5 & TOP |
|  | **C** | Any trade in any area. |

1. ## Coinring

      - *Description:** *Upgrades your bank.***

|  | **Part** | **Gained from** |
| --- | --- | --- |
|  | **A** | **/sell** any item. (Includes seeds and life potions! Estimated "cost" (*total lost from buying and re-selling*) (Seeds are more efficient, since selling items WORTH more has a higher chance of dropping the part.) |
|  | **B** | Using the gambling command **/slots** and winning. |
|  | **C** | Buying lootboxes from **/shop** |


----

1. ##  Golden Pan 

      - *Description:** *Keeps 2% of the cooked stats after a time travel, ability to refresh alchemy boosts and multiplies x10 the cooking cap, gets higher with time travels.***

|  | **Part** | **Gained from** |
| --- | --- | --- |
|  | **A** | Level up through XP commands |
|  | **B** | Through using **/cook**. |


----

1. ##  Master Key 

      - *Description:** *Skips a single player dungeon in each time travel (11-14), it will not be possible to benefit of this item if the corresponding dungeon was not unlocked yet.***

|  | **Part** | **Gained from** |
| --- | --- | --- |
|  | **A** | Doing any dungeon 1-9 and 16-20. |
|  | **B** | **Adventure** commands in Area 11 to 15 |
|  | **C** | Enchanting commands (All abbreviations are eligible, the higher tier the command, the more chances of getting it.) |


----

1. ##  Pocket Watch 

      - *Description:** *Adds a cooldown reduction of 1% and doubles the time of all boosts, gets better with time travels.***

|  | **Part** | **Gained from** |
| --- | --- | --- |
|  | **A** | Pets claim (on adventure return) |
|  | **B** | Time Travelling, Super Time Travelling or Using a Time Capsule. Chance increases depending on total TT Count |
|  | **C** | **/Forge** items |
|  | **D** | **/Weekly** |
|  | **E** | Adventure commands in TOP (This is easily the hardest of all the items to obtain, as it's requirement is endgame) |
