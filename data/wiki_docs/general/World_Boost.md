# World Boost

Command: **/world status**

With **/world status**, players can see what weekly profession, daily monster, and general boosts are currently active that will provide bonuses while playing. 

1. #  **Weekly Profession** 
Each week, at Monday 0:00 UTC, a random profession will be chosen to get a boost of **+10% exp** when performing the working commands that pertain to it. 

See professions for more info on descriptions and commands.

1. #  **Daily Monster** 
Each day, at 0:00 UTC, a random monster will be chosen to get a boost of **+10% drop chance** and **+25% exp and coins**. 

See Areas (Ver: Area#Areas) for a list of where to find which monsters are in which respective areas.

1. #  **General Boosts** 
These boosts do not have a set time for reset like how weekly profession and daily monster do. Instead, these boosts can be triggered via the purchase of magic chairs found in the guild shop and magic beds found in the epic shop. Magic chairs will boost **lootbox drop chance to x1.2** while magic beds will boost **mob drop chance by x1.2**, both affecting the chances for all players. Each item lasts for only 45 minutes and there can only be one of each boost active at a time.
