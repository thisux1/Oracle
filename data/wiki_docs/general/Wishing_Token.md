# Wishing Token

The wishing token  is a consumable added on EPIC RPG 5th anniversary that can be used to wish for a select option of rewards with each having it's own separate chance for the wish to be successful depending on the rarity of the wish. If the wish fails you get given 1 time cookie instead. 

It can be used with <code>rpg use wishing token [amount]</code> or  **/use item: wishing token** and it will give you a list of rewards like this and if you don't click on the buttons or if you press the green X then it will back out of it without spending the wishing token
Note: If you used multiple wishing token at once it won't increase the chances but instead multiply the reward 

    - Sources**

Wishing token can be obtained through these sources:

- Using daily during Anniversary and New Year Event (Ver: Special Events#New Year Event)
- Opening Anniversary lootbox
- Opening Compensation lootbox
- Codes
